# Android 実機 E2E チェックリスト(Play 公開前)

作成: 2026-06-23 / 対象: 1.4.0(犬12種+セキュリティ堅牢化+ウィジェット拡大)

実機/エミュでは検証できない・本番インフラ依存の項目を、Play 公開(クローズドテスト)前に確認する。
バックエンドは **Supabase**(CloudKit ではない)。各項目「期待結果」を満たしたら ✅、満たさなければ再現手順をメモ。

> 前提: 出荷用 AAB(`PLAY_BILLING_ENABLED=true` / `FRIENDS_GOOGLE_LINK_ENABLED=true`)を
> クローズドテストのトラックに上げ、ライセンステスター/テスター端末で確認する。
> 実機が無い項目はクローズドテスター(20名)の協力で代替可。

## 0. 前提セットアップ(本番インフラ側・先に完了)
- [ ] Google Cloud: アップロード鍵の SHA-1/256 を OAuth クライアントに登録 / `GOOGLE_WEB_CLIENT_ID` 発行
- [ ] Supabase: redirect `goexercise://auth-callback` を allowlist・Google provider 有効
- [ ] Play Console: サブスク `com.goexercise.app.premium_monthly`/`_yearly`(14日トライアル)を「有効」
- [ ] ライセンステスター(Play Console → 設定 → ライセンステスト)に自分のメールを登録(課金が無料で試せる)

## 1. 課金(最重要・審査リジェクト頻出)
- [ ] ペイウォール表示(設定プレミアム行 / 体重タブ / ロックされた相棒 / 保険チケット の各導線)
- [ ] 価格が **¥表示**(月¥500 / 年¥3,800)。トライアル文言「14日間無料」が適格時のみ表示
- [ ] 月額購入 → プレミアム解放(犬/猫の全種ロック解除・体重タブ等)
- [ ] 年額購入 → 同上
- [ ] 「購入を復元」→ 別端末/再インストール後にプレミアム復活
- [ ] 解約導線(Google Play の定期購入)案内が機能

## 2. アカウント/バックアップ(Supabase・OAuth)
- [ ] Google サインイン往復(ネイティブ)→「Google アカウントでバックアップ中」緑表示
- [ ] Apple サインイン往復(Web/PKCE)→ 緑表示
- [ ] クラウドバックアップ ON → 記録1件 → 今すぐバックアップ → アンインストール → 再インストール → サインイン → **履歴に復活**(機種変更シナリオ)
- [ ] **iOS ↔ Android 相互**: iOS で作った友達コードで Android から友達追加(クロスOS契約)
- [ ] アカウント削除(設定 → アカウントとバックアップ → 削除)→ サーバの共有プロフィール/友達/応援/認証が即時削除

## 3. 友達(Supabase)
- [ ] 友達コード/QR で申請 → 承認 → 相互に表示
- [ ] QRカメラ起動・読み取り(エミュ不可・実機必須)
- [ ] 応援スタンプ送信 → 相手の受信トースト表示(2アカウント)
- [ ] 週間ランキング表示(猫犬混在アバター)

## 4. 犬(1.4 新機能)
- [ ] オンボーディングで犬を選べる(猫/犬セグメント・犬12種)
- [ ] 設定 → キャラ変更で犬に切替(プレミアム/⭐10 解放後)→ ホームに犬が描画
- [ ] 称号が犬対応(「みならい犬」「レジェンド犬」等)
- [ ] 友達には my_cat_breed 経由で表示(旧クライアントは既定猫フォールバック)

## 5. ウィジェット / 通知
- [ ] ホームに**中ウィジェット**配置 → 週ストリップ(曜日・達成ドット)が**大きく**表示(iOS パリティ)
- [ ] 小ウィジェット配置 → コンパクト表示
- [ ] ウィジェットタップ → アプリのホームへ遷移
- [ ] 通知の実発火(朝/夕)・タップでホームへ deep-link・当日達成済みは抑制

## 6. セキュリティ堅牢化(1.4・実機確認)
- [ ] **平文→暗号DB移行**: 1.3(または旧 dev ビルド)で記録を作成 → 1.4 に**アップデート**(新規インストールでなく上書き)→ 記録が消えずに読める(SQLCipher 移行成功)
- [ ] レート制限: 短時間に大量の応援/友達申請を試行 → サーバが弾く(任意・濫用テスト)
- [ ] 友達追加が「申請→承認」「招待コード」両経路で成功(V1 トリガ適用後=PART2 デプロイ後に再確認)

## 7. 堅牢性(クラッシュしない)
- [ ] プロセス kill 後の復帰 / 画面回転 / 機内モード(ネット断)でクラッシュしない
- [ ] エミュのネット不達(VPN)で友達タブが welcome に留まる現象はアプリのバグではない(`adb shell ping -c1 1.1.1.1` で疎通確認)

- iOS 側の同等手順は `docs/DEVICE_QA_RUNBOOK.md`(ただし一部 CloudKit 前提で古い・Supabase に読み替え)。
