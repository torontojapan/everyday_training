# 大規模 UI/UX 刷新提案 — Claude (Opus 4.7) 視点

スクショ・スクリプト全部 + これまでセッションで重ねた小改善 (Phase 6.0–6.8) を踏まえた **「今のままの延長線上ではない」提案**。Gemini と被らない独自視点に絞っている。

## エグゼクティブサマリー

**「アプリを開く必要をなくす」** — App Intents + Interactive Widget + Live Activity の組み合わせで、運動記録の 8 割をアプリの外で完結させる。アプリは「猫と暮らす場所」に純化させ、開いた時の体験 (Tamagotchi 的、感情を動かす) を最大化する。記録は機能、猫は目的、という主従の入れ替え。

---

## 大方針

1. **iOS の OS 機能フル活用で「アプリレス記録」**
   - **Interactive Widget** (iOS 17+): ロック画面 / ホーム画面のウィジェットを直接タップで記録 (アプリ起動不要)
   - **App Intents** (iOS 16+): 「ヘイ Siri、スクワット 20 回完了」「ヘイ Siri、今日の運動」
   - **Live Activity / Dynamic Island**: 朝〜夜の間、猫が常時 Dynamic Island で待っている
   - **Lock Screen Widget**: 連続記録 + 猫が一目で

2. **「Tamagotchi 化」 — 機能ではなく感情の階段**
   - メインのインタラクションは「記録」ではなく「猫に会う」
   - 連続記録 = 猫との絆度
   - ホームを開く動機が「タスク確認」から「会いたい」になる

3. **罪悪感を完全に排除する 4 つの仕組み**
   - 「サボった日 = 無」ではなく「ねこ撫でた日 = カウント済み」
   - 過去の失敗が視界に入らない (Gemini と一致)
   - 達成日のみが視覚的に残る "Positive-Only Calendar"
   - 連続が切れる時の演出を「再出発の儀式」にする (慰める / 励ます)

4. **「並走モード」 = 友達と非同期に同時運動**
   - 友達のアバターが「今この瞬間運動中」とリアルタイム表示
   - こちらも記録を始めると相手側にも通知 (相互の支え合い)
   - 同期セッションを設定で予約 (毎週月曜 8:00 など)

5. **Apple Watch コンパニオン** — 手首で完結 (将来拡張)

## 画面別の再設計案

### ホーム = 「猫劇場」

```
┌────────────────────┐
│       9:41    🔥27日 │  ← ステータスのみ最上部
├────────────────────┤
│                    │
│                    │
│     [猫が大きく]   │  ← 画面の 55%、猫を主役
│     ふわふわ動く    │
│   ストレッチしてる   │
│                    │
├────────────────────┤
│   「今日も少しずつ」  │  ← 猫からの吹き出し
│                    │
│  ┌──────────────┐  │
│  │ ぽちっと記録 │  │  ← FAB 風、画面下 1/4
│  └──────────────┘  │
│                    │
│  あきら 5分前運動中  │  ← 友達の気配 (オプション)
└────────────────────┘
```

- **猫の身長 200pt 級**: 72pt 円から脱出、ホームの主役に
- **背景は時刻 + 季節で hue 変化**: 朝はやさしいピンク、夜は深い藍
- **数字を消す**: 累計 / 週間達成率は履歴タブへ
- **CTA は 1 つだけ**: 「ぽちっと記録」

### 記録 = 「半 sheet で 3 タップ」

```
┌────────────────────┐
│  [現在のホーム]      │
│  ↑ 残り表示          │
├ハーフシート─────────┤
│      ✕               │
│                    │
│  [筋トレ] [有酸素]  │  ← 6 カテゴリ、大きい
│  [ヨガ]   [ストレ]  │
│  [筋膜]   [その他]  │
│                    │
│  ★ おすすめ:        │
│   スクワット 1分     │  ← 履歴から推測
│   ↓ タップで完了    │
└────────────────────┘
```

- **3 タップで完了**: カテゴリ → おすすめ種目 → 「やった」
- **詳細は後付け**: 完了後の Snackbar に「+ メモ」「+ 体重」「+ 回数」
- **おすすめは履歴から AI 提案**: 「いつもこの時間スクワットしてる」

### 友達 = 「猫公園」 (Gemini に同意)

- ランキングはタブ内のセグメントで「順位 / 公園」を切替可能
- デフォルトは「公園ビュー」: 友達の猫が散らばって配置、座っている / 寝ている / 体操中で達成状況を表現
- タップで cheer 即送信、長押しでメニュー

### Stats タブ (新規) = 「成長の記録」

- 月間カレンダー (過去達成のみ表示、未達成は薄く)
- 体重グラフ
- 累計達成日数
- 月次レビューカード
- ストリークの「線」: 1 日 1 ドット、つながった日が太い線で表示

### Settings = 「マイページ」

- 猫の選択
- 通知設定
- テーマ
- プライバシー (共有設定)
- 自動休養日ヘルプ
- アプリ情報

## あなたが大胆だと思う提案 1 つ

**「アプリを開かずに記録を完結」 — Interactive Widget が主、アプリ本体は副**

ロック画面ウィジェットに **「今日の運動」ボタン** を置く。タップ → ハプティック → 即「達成」記録。これだけ。アプリ起動不要。

iOS 17+ の Interactive Widget + App Intents で実装可能。ユーザーはアプリを開く必要がなくなる代わりに、開いた時 (アプリ起動時) は「猫に会いたかった」が動機になる。

これにより:
- 「面倒で記録忘れる」が消滅 (ロック画面で 1 タップ)
- アプリを開く動機が「タスク」から「感情」に
- App Store カテゴリで他のフィットネスアプリと差別化 (記録の手軽さで圧勝)

技術的には `WidgetKit + AppIntent + IntentDescription` で 1-2 日。
