# UX 改善提案 — Claude (Opus 4.7) 視点

スクリーンショット (1-6 枚目) + 主要 View ファイルの実装を見て、Codex / Gemini と独立に出した提案。Codex/Gemini と重複する項目は除外して、Claude 独自の視点に絞っている。

## P0 — 高インパクト

### ホーム: 達成済み状態で CTA とメッセージが変わらない
`HomeView.swift:33`、`HomeView.swift:161`

- スクショ 1 では「30日連続」「12日連続」が表示されるが、達成済みでも「今日の運動を記録する」CTA と「あとX時間」がそのまま。
- **修正**: 達成済みなら CTA を「もう一種目する 🔥」(secondary scale) に変更、ヘッダーの「あとX時間」も「今日は達成済み ✨」のお祝い chip に切り替える。

### RecordEntryView: カテゴリは Chip ではなく Segmented Control
`RecordEntryView.swift:20-32`

- 「カテゴリ」が横スクロール chip で 1 つしか選べない仕様。複数選択風に見えて誤解しやすい。
- **修正**: `Picker(selection:) { ... }.pickerStyle(.segmented)` に変更。一目で「単一選択」が伝わる + 全 6 カテゴリを 1 画面に収められる (2 行 × 3 カラム の Grid でも可)。

### 友達一覧: 自分のプロフィール + QR で画面の 60% を占有
`FriendsView.swift:108-160`

- スクショ 3 を見ると、ジュン (自分) のカード + 友達コード + QR で**スクロールしないと友達が見えない**。
- **修正**: QR は「QR を表示」ボタンの **DisclosureGroup** に折り畳む。デフォルト閉。これで友達リストが ファーストビューに来る。

## P1 — 価値ある改善

### 友達カードの情報密度が高すぎる
`FriendsView.swift:289-356`

- 装飾色 / 名前 / 連続日数 / 累計 / 今日達成 / カテゴリ chip / 種目名 / **週カレンダー 7 マス** / cheer 4 ボタン — これが**カード 1 つに全部**。スクショ 3 でも 1.5 枚しか入らない。
- **修正**: カードは「装飾 + 名前 + 連続 + 今日達成 ○/× + 更新時刻」に絞る。週カレンダー / cheer は詳細シートに移す (既に FriendDetailView にあるので重複)。

### 種目追加時に「種目 1」「種目 2」のラベルがない
`RecordEntryView.swift:34-45`

- 複数追加時、編集中の種目がどれか視覚的に分からない。
- **修正**: ExerciseInputRow の上に `Text("種目 \(index + 1)").font(Typography.caption).foregroundStyle(Palette.textSecondary)` を表示。

### cheer 4 種が全カードに常時表示 → タップ範囲圧迫
`FriendsView.swift:333-353`

- がんばれ / すごい / 拍手 / 応援 — 4 ボタンが全友達カードに毎回出ている。
- **修正**: カードには「応援を送る」1 つのボタンだけ、タップで bottom sheet に 4 種を出す。長押しで「最後に使ったスタンプ」を 1 タップ送信のショートカット。

### 連続記録 chip がタップ可能に見えない (実はシェア画面に飛ぶ)
`HomeView.swift:155`、`StreakBadgeView.swift`

- スクショ 1 の「30日連続」chip は実はタップで `StreakShareSheet` を開くが、見た目が静的 chip でアフォーダンスがない。
- **修正**: 右側に小さな `chevron.right` か `square.and.arrow.up` アイコンを追加。

### 「達成完了画面」のスクショが撮れない = ストア訴求が弱い
今のスクショ提出物 6 枚に **祝祭演出 (CelebrationOverlay)** が入っていない。スクショ 1-6 で「達成感」が伝わるシーンがない。
- **修正**: `--mock-show-celebration legendary` のような launch arg を追加して、`CelebrationOverlay` を発火状態でアプリ起動できるようにする。スクショ 7 枚目として追加。

### オンボーディングがない
- 初回起動でいきなりホーム画面 → アプリの世界観 (1 分で OK / 自動休養日 / 連続記録ルール) が伝わらない。
- **修正**: 初回起動時に 3 ページの Welcome ツアー (`@AppStorage("hasSeenOnboarding")` でガード)。
  1. 「猫と一緒に、毎日 1 分から」
  2. 「週 2 日まで休んで OK」
  3. 「友達と励まし合おう」

## P2 — Polish

### 「今日の達成」カードと「今週のハイライト」が情報重複
`HomeView.swift:39-48`

- スクショ 1: 「今日の達成」(種目 2、合計 0 分) と「今週のハイライト」(合計時間 0 分、よく使う種目) — 似た数値が並んでいる。
- **修正**: 達成済み日は「今日の達成」のみ、それ以外は「今週のハイライト」のみと、排他的に出す。

### LeagueView のリーグ説明 chip が長文
`LeagueView.swift:90-95`

- 「上位 2 名で シルバー昇格、下位 1 名で ブロンズ降格」が hero card 内に常時表示で重い。
- **修正**: hero card は「ブロンズリーグ」だけ大きく出し、ルール文は info アイコン → tap で popover or sheet。

### Settings の演出セクション「演出 (振動)」と「友達と共有する情報」が並列だが関連性ない
`SettingsView.swift:43-71`

- 「演出」と「プライバシー (共有設定)」は別概念なのに隣接している。
- **修正**: セクション順を「通知 / 外観 / 体調・周期 / 体重 / **プライバシー (共有設定)** / 演出 / 保険チケット / ウィジェット / 自動休養日 / アプリ情報」に再構成。

### EmptyStateView のメッセージが「友達コードでつながろう」だけ
`FriendsView.swift:226-231`

- 初回開いた時の動機付けが弱い。
- **修正**: 「友達コードを共有 → QR / メッセージ / Twitter で送信できる」のように **次の操作** を提案するイラスト or ボタン付き emptystate。
