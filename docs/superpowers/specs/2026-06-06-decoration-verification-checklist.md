# 達成の豪華演出リデザイン 検証チェックリスト(A〜F)

> 正本設計: `2026-06-06-achievement-luxury-design.md`。本書はその実装を 3LLM スクショ + Codex 改善ループで
> 検証するための**検証項目**。ad-hoc な「見て良い?」を廃し、各項目に合否バー(0–3点・全項目2点以上で合格)を置く。
> 検証は各計画(①装飾 / ②フリーズ / ③シェイカー)の実装後に該当軸を回す。

## 共通の方法
- **Claude(私)** が simctl で自分でスクショを撮る(UIUX は必ず自分の目で確認)。
- 同一スクショを **Codex(gpt-5-codex)** と **Gemini** で独立採点(画像はワークスペース内に置いて実読を担保)。
- 純ロジックは swiftc ネイティブ実行で検証(sim テストランナーは hang するため)。
- ビルド: `JAVA_HOME` は不要(iOS)。`xcodegen generate` 後に `xcodebuild build`。
  ※ xcodegen は Info.plist の手動キー(FriendsAppleLinkEnabled / TelemetryDeckAppID)を落とすので Archive 前に要確認。
  ※ iCloud 重複ファイル: 一括操作後 `find app/.../build -name "* [0-9].*" -delete` + clean。

## A. 背景(MilestoneBackdrop・連続ランク駆動)
1. **ランク識別性**: 0/7/30/100/365/500 で背景の濃さ・色帯(琥珀→銀→金→白金→虹)が一目で上位と分かる。
2. **上品さ**: チープ/カード感ゼロ。眩しすぎない(過去指摘の 365/500 の黄色過多を回避)。
3. **時間帯トーン**: 朝/昼/夜で破綻しない。ライト/ダーク両対応。
4. **猫との調和**: 大猫が背景に埋もれず主役。
5. **リセット挙動**: 連続が切れると淡くなり、フリーズ復活で即戻る(D と連動)。
6. (コード)reduceMotion で粒子/光帯が静止。パフォーマンス。

## B. 瞬間演出 + cadence
7. **小節目オーバーレイ**: ランク昇格/週次で、フルシート無しの軽量演出(光のさざ波+ハプティクス+称号トースト)が出る。割り込まない。
8. **称号トースト**: 称号名が読め、自動で消える。
9. **大節目との非二重**: 同日に大節目シートが出る時、小節目が重複しない。
10. **細かさの体感**: 最初の100日で 1〜2週おきに必ず何か起きる(cadence 表どおり)。

## C. 称号バッジ(RankBadge)
11. **メタリック質感**: bronze→silver→gold→platinum→虹 が質感で判別でき、上品。
12. **配置**: 「○日連続」隣で被らず収まる。rank0(連続7日未満)は非表示。
13. **昇格 shimmer**: 昇格時に斜めハイライト+pop が一度流れる。
14. (コード)VoiceOver で「称号 ◯◯ネコ」を読む。

## D. フリーズ復活ポップ
15. **発火条件**: 連続が途切れ、missed 日が直近4日以内のときだけポップ。5日目以降は出ない。
16. **無料枠で復活**: 残枠ありで適用→連続/称号/背景が即復活+復活演出。
17. **枠切れ→ペイウォール**: 残枠0で `PremiumPaywallSheet` に導線。
18. **節度(ダークパターン回避)**: ディスミス可・1起動1回・煽りすぎないコピー。
19. (コード)`StreakFreezeWindow` 純ロジック: 4日境界/複数日 missed/休息日混在/残枠0。

## E. シェイカー猫(全11猫種)
20. **トンマナ統一**: 11猫種で線・塗り・画風が既存アートと揃う。**青色滲み無し**(過去の variant 一掃原因)。
21. **構図**: シェイカーが手・体と自然。猫種ごとに破綻しない。
22. **表示タイミング**: 運動記録の前後(RecordCompletion ヒーロー/ホーム未記録)で出る。
23. (コード)欠落時フォールバックが効く(通常 waitingMorning / orange shaker)。

## F. 称号の友達共有
24. **友達カードに称号**: `CatRank(friend.currentStreak)` の `RankBadge` が友達一覧/パークに出る。
25. (コード)バックエンド変更なし。`decoration`→`rank` 置換で既存 `FriendsStoreTests` green。
