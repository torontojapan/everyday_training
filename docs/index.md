# 🐱 GO エクササイズ

猫キャラクターと一緒に、毎日1分から運動を習慣化する iOS / Android アプリ。

> 🐱「今日も1分だけやってみよ？」

## 特長

- 🔥 **1分でOK** — 1種目以上、または1分以上の運動で「今日も達成」
- 📅 **連続記録 + 週間達成率** — 続けるのが楽しくなる可視化
- 😴 **自動で休養日** — 週2回までの未記録日は「回復日」扱い、連続記録は維持
- 🐱 **7状態の猫キャラ** — 朝はにこにこ、夜はそわそわ、達成したら大喜び
- 📲 **ウィジェット** — ホーム画面に残り時間 / 達成率 / 猫メッセージ
- 🔔 **やさしい通知** — 1日2回、時刻はいつでも変更可

## プライバシー方針

運動・体重・体調の記録は **原則として端末内のみに保存**します。ログイン不要で使えます。
設定で「記録をクラウドにバックアップ」(任意・既定オフ)をオンにした場合のみ、機種変更・再インストール時の
復元のために本人だけが読み書きできる領域へ保存されます(友達を含む第三者には公開されません)。
**友達機能を使う場合**、表示名・連続記録などの共有プロフィールが、匿名認証(ログイン不要)の
外部データベース(Supabase)に保存されます(実績の共有は友達としてつながった相手のみ)。
**広告なし・行動トラッキングなし**。利用状況の分析は匿名で、設定からいつでもオプトアウトできます。
詳しくは[プライバシーポリシー](privacy)をご覧ください。
