# Task: 大規模 UI/UX 刷新提案 for GOエクササイズ iOS app

このアプリの仕様上、もっとも最適な UI/UX を再設計してほしい。
**現状の改善でも、ゼロから別物に再構築する案でも OK。スコープ制限なし。**

## アプリの本質 (これは変えない)

- 名前: GOエクササイズ (GO Exercise)
- ターゲット: 日本の個人ユーザー、運動習慣化したい人
- 設計哲学:
  - 「1 分でいい」軽量化
  - 「無理させない」(週 2 日まで自動休養日)
  - 「猫キャラと一緒に」
  - 「連続記録」を励みに
  - 「友達と励まし合う」(オプション)

## 現状の機能 (これは資産として活用可)

1. 運動記録 (6 カテゴリ: 筋トレ / 有酸素 / ヨガ / ストレッチ / 筋膜リリース / その他)
2. 連続記録 + 週間達成率 + 月間カレンダー
3. 自動休養日 (週 2 日まで)
4. 11 種類の猫キャラ (ユーザーが選択) × 7 状態 (時間帯と達成状況で変化)
5. 4 段階の祝祭演出 (CoreHaptics + アニメ)
6. 通知 (1 日 2 回ローカル)
7. ホームウィジェット (Small / Medium)
8. 友達機能 (友達コード / QR / 申請 / 応援スタンプ / 週月ランキング)
9. 体重・体調記録 (オプトイン)
10. 保険チケット (月 1〜2 枚、未達成日を救済)
11. 達成日数に応じた装飾 (バンダナ→王冠)
12. 月次レビュー + 連続記録シェア画面

## あなたへの依頼

**「人間が使いやすい最適な UIUX」を提案** してください。視点:

1. **情報設計 (IA)**: タブ / 階層 / ナビゲーション構造はそのままで良いか、別物にすべきか
2. **第一印象 (ホーム画面)**: アプリ起動直後の 3 秒で「今日何すれば良いか」が伝わる設計
3. **記録の摩擦最小化**: 「1 分でいい」を実現する入力体験 (現状は Form ベース)
4. **モチベーション設計**: 達成感 / 継続のフィードバック / 罪悪感を避ける仕組み
5. **友達と一緒の体験**: 通知 / cheer / 競争 / 比較の塩梅
6. **片手操作のエルゴノミクス**: 親指届きやすさ、ボトムアクション
7. **iOS らしさ**: HIG / SF Symbols / Dynamic Type / Dark Mode 配慮
8. **数字を見せすぎない**: 圧迫感を避ける情報の出し方
