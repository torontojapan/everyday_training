# 猫種(breed)の課金解放 設計

- 作成日: 2026-06-05
- 対象: GOエクササイズ(iOS / Android 共通設計)
- 目的: 猫種の選択をプレミアム特典にし、コスメ差別化でプレミアム価値・転換を高める。
- 関連: 既存 CatBreed(11種・各7状態=77画像は既存) / UserCatPreferences / StoreKitManager.isPremiumActive。達成装飾([[2026-06-05-achievement-decorations-design]])と相乗り。

## 1. ゴールと非ゴール
- ゴール: 無料=オレンジ限定 / プレミアムで11種から選び放題。機能でなく見た目のみを課金対象にする(規約安全)。
- 非ゴール: 猫種ごとの能力差(あくまで見た目)。新規の単発課金商品(既存のプレミアム購読に内包する)。

## 2. 仕組み(購読特典 + 解約後も維持)
- **無料(未購読)**: 既定=**オレンジ**。breed 変更は不可(ロック)。
- **プレミアム購読中**: 11種から**いつでも変更可**。
- **解約後(lapse)**: **今表示している猫はそのまま維持**。ただし**変更操作は不可**(再購読で再び変更可)。
  - = 「愛着ある猫を失う」嫌な体験を避けつつ、変更の自由を購読価値にする。

## 3. 実装方針(軽量)
- breed の保存は既存 `UserCatPreferences`(変更なし)。**stored breed は購読状態に関わらず永続**。
- breed 選択UI(ピッカー)の**「変更を確定する」操作を `StoreKitManager.isPremiumActive` でゲート**:
  - 未購読: 非オレンジを選ぶ/変更しようとすると **ペイウォール**(`PremiumPaywallSheet`, context 追加)へ。表示は全11種を見せつつ非オレンジに🔒。
  - 購読中: 自由に変更・保存。
- 新規ユーザーの既定 breed を**オレンジに固定**(現状の「初期から複数選択可」から変更)。
- **base アート追加は不要**: 77画像(11×7状態)は既存。本機能はゲートのみ。

## 4. 達成装飾との相互作用
- 無料=オレンジのみ稼働 → 装飾の**装着アイテム焼き込みの最小必要アートは「オレンジ+シェイカー/王冠」**で足りる。他10 breed のアイテム画像は**プレミアム利用者向けに段階導入**でよい(背景はbreed共通なので影響なし)。

## 5. ソーシャル表示
- friends は `myCatBreed` を既に同期。無料ユーザーはオレンジ、プレミアムは選択した breed が友達にも見える(プレミアムの可視的フレックス=さりげない宣伝)。

## 6. ストア規約
- コスメ解放を**既存のプレミアム購読(IAP)**で提供・核心機能は無料のまま → App Store / Google Play 適合。

## 7. オープン事項(実装計画で詰める)
- ロック中ピッカーの見せ方(全種表示+🔒+「プレミアムで解放」CTA)。
- ペイウォール context に「猫を選ぶ」訴求を追加。
- 解約検知から「変更不可」への即時反映(`isPremiumActive` 監視は既存パターンを流用)。
- 既存のオンボーディング/設定の breed 選択導線の改修箇所。

## 8. リリース位置づけ
- 現在審査中の iOS 1.0(3) には含まない。**将来版(v1.1+)** 向け。Android も開発中の本線に組み込み可能。
