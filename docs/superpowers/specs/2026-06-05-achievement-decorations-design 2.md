# 達成マイルストーン装飾 設計

- 作成日: 2026-06-05
- 対象: GOエクササイズ(iOS / Android 共通設計)
- 目的: `totalAchievedDays` に応じて猫の見た目(背景+装着アイテム)を育て、継続のモチベーション/定着を高める。友達にも見える「育成の見える化」。
- 関連: 既存の [[CatDecoration]](app/GOExercise/GOExercise/Models/) / CatBreed(11種)。**猫種の課金解放は別スペック**(本書スコープ外、ただし§7で相互作用を明記)。

## 1. ゴールと非ゴール
- ゴール: 達成日数で猫の装飾が継続的にグレードアップ。100日以降も上のランクが出続ける。友達のプロフィールでも見える。
- 非ゴール: 装飾の購入/トレード、装飾によるゲーム機能のアンロック(あくまで見た目のみ)。

## 2. アート方式 = 焼き込み(方式A)+ ヒーロー表示限定
- 過去に「キャラ画像へ装飾を重ねる overlay」が二重描画のシミ不具合で撤去された経緯があるため、**装着アイテムは breed ごとに猫アートへ焼き込む**(overlay しない)。
- 装飾は**ヒーロー表示(ホーム/プロフィールの主ポーズ)1状態のみ**に適用。7状態すべてには適用しない(組合せ爆発回避)。
- **背景は猫の「後ろ」のレイヤー**(猫の上に重ねないので安全)。breed 非依存=全 breed 共通で1枚。

## 3. 進行モデル(totalAchievedDays 一本で駆動)
- 既存の単一ランク式 [[CatDecoration]](チップ表示の bandana/headband/medal/crown)は**退役**し、本システムへ一本化。猫の素アート(描き込み済みの服等)はベースのまま不変。
- すべての装飾解放は `totalAchievedDays` から算出。friends は `total_achieved_days` を**既に Supabase 同期済み**のため、**友達の装飾もクライアント算出で同じ見た目を再現できる = Supabase スキーマ変更ゼロ**。

### 3.1 背景(主役・キュレート多段・breed共通)
デザイナー定義の名前付き背景を多数用意し、日数しきい値に紐付ける。提案ラダー(微調整可):

| 日数 | 背景 |
|---|---|
| 7 | Lv1 |
| 14 | Lv2 |
| 30 | Lv3 |
| 50 | Lv4 |
| 75 | Lv5 |
| 100 | Lv6 |
| 150 | Lv7 |
| 200 | Lv8 |
| 300 | Lv9 |
| 365 | Lv10 |
| 500 | Lv11 |

- 各 Lv = breed 非依存の背景画像1枚。以降も段を追加可能(継続)。
- 現在の達成日数に対応する**最高ランク背景を自動表示**。

### 3.2 装着アイテム(breedごと焼き込み・累積)
| 日数 | アイテム |
|---|---|
| 30 | 🥤 プロテインシェイカー(手) |
| 100 | 👑 王冠(頭) |

- 累積: 100日以降は**シェイカー+王冠の両方**(頭と手で干渉せず共存)。
- breed ごとに「素 / +シェイカー / +シェイカー+王冠」のヒーロー画像を焼き込み。

## 4. レンダリング
- 合成順: **[背景レイヤー(その時の最高ランク)] → [焼き込み済みヒーロー猫画像(その時のアイテム状態)]**。
- 背景は猫の後ろなので overlay 不具合は起きない。アイテムは焼き込み済みで overlay しない。

## 5. ソーシャル表示
- 友達プロフィールでも、その友達の `total_achieved_days` から §3 の対応表で算出し、同じ背景+アイテムを表示。**新規カラム不要**。

## 6. アート生成
- 背景・アイテム入りヒーロー画像は Codex で生成([[codex_image_generation]] の透過/flood-fill パターン)。
- 最小セット: 背景 Lv1..N(共通)+ 各 breed の「+シェイカー」「+シェイカー+王冠」ヒーロー。

## 7. 猫種課金解放(別スペック)との相互作用
- 別途検討中の「無料=オレンジ限定 / 課金で全 breed 解放」を採用する場合、**無料ユーザーはオレンジのみ** → アイテム焼き込みの**最小必要アートはオレンジ+シェイカー/王冠**で済み、他10 breed のアイテム画像は段階導入でよい(背景は共通なので影響なし)。

## 8. オープン事項(実装計画で詰める)
- 背景の段数・しきい値・テーマの確定。
- 過去ランク背景を選べる「ギャラリー」UI(v2 候補)。
- ヒーロー表示の単一ソース化(現在の breed×state アセット解決に、装飾レイヤー選択を差し込む箇所)。
- 退役する旧 CatDecoration チップの参照箇所の置換。
