# アカウントの削除 — GO エクササイズ

**最終更新日: 2026-06-03**

GO エクササイズ（以下「本アプリ」）では、いつでもご自身のアカウントとデータを完全に削除できます。
本ページは、App Store / Google Play の審査要件（アプリ内アカウント削除導線の明示）に基づく案内です。

## アプリ内から削除する（推奨）

友達機能でアカウントを作成・連携している場合、アプリ内から削除できます。

1. アプリを開き、「友達」タブを開きます。
2. 画面下部の「**アカウントを削除**」をタップします。
3. 確認ダイアログで「**アカウントを削除**」を選びます。

削除すると、ただちに以下がサーバーから完全に削除され、元に戻せません。

- 友達コード・プロフィール（表示名・ユーザー名・連続記録などの共有情報）
- 友達関係・申請・応援（cheer）の履歴
- Apple / Google 連携情報および全セッション

> 注: バックアップ（Apple / Google 連携）済みでも、削除後は復元できません。

## アプリを使わずに削除を依頼する

端末をお持ちでない・アプリを開けない場合は、以下のフォームから削除をご依頼ください。
ご本人確認のため、登録時の**友達コード**を添えてください。

- **削除依頼フォーム**: [こちらからお送りください](https://forms.gle/Ljbaj4MvW2YPmyJ99)

ご依頼受領後、原則 **30 日以内**に対象データを削除し、完了をご連絡します。

## 削除されるデータ / 保持されるデータ

| 種別 | 削除 | 備考 |
|---|---|---|
| 友達コード・共有プロフィール | ✅ 即時 | サーバーから cascade 削除 |
| 友達関係・申請・応援 | ✅ 即時 | |
| Apple / Google 連携・セッション | ✅ 即時 | 全セッション失効 |
| 端末内のローカルデータ（運動記録・体重・設定） | アプリ削除で消去 | 端末ローカルのみ。クラウド送信なし |
| 課金（サブスクリプション） | 各ストアで管理 | 解約は App Store / Google Play の定期購入管理から |

運動記録・体重などの健康データは**端末内（ローカル）にのみ保存**され、クラウドには送信していません。
アプリをアンインストールすると、これらのローカルデータも端末から削除されます。
