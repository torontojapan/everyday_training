# GO エクササイズ iOS版 仕様書・要件定義書

> 対象バージョン: **iOS 1.1 (build 5)** ／ 最終更新: 2026-06-10
> このドキュメントは、開発者でなくても全体像がわかるように、アプリの目的・画面・ルール・技術を簡潔にまとめたものです。

---

## 0. 一言でいうと

**「運動を1日1回記録するだけで、猫のキャラと一緒に運動習慣を続けられるアプリ」** です。
連続記録(ストリーク)・称号・友達との励まし合いでモチベーションを保ちます。日本のみ配信。

---

## 1. 要件定義(なに を なぜ つくるか)

### 1.1 目的・ゴール
- ユーザーが**運動習慣を無理なく継続**できること。
- 「完璧でなくていい」設計(自動休養・連続フリーズ・復帰モード)で挫折を防ぐ。
- 友達・紹介・課金で継続と収益化の両立を図る。

### 1.2 想定ユーザー
- 運動を習慣化したい個人(日本国内)。スポーツ専用というより**ゆるい毎日の運動**が中心。

### 1.3 スコープ(このバージョンに含むもの)
- 運動記録、連続記録、自動休養、連続フリーズ、称号、月次レビュー
- 体重管理(プレミアム)、友達、友達紹介、ローカル通知、ウィジェット/Live Activity
- 匿名アカウント+Apple/Google連携によるバックアップ・復元、アカウント削除

### 1.4 スコープ外(このバージョンでやらないこと)
- リモートプッシュ通知 / SNS的なタイムライン / 動画・写真投稿
- ブロック・通報などのUGC安全機能(審査指摘があれば追加)

### 1.5 非機能要件
| 区分 | 要件 |
|---|---|
| 対応OS | iOS 17.0 以上(iPhone / iPad) |
| 配信地域 | 日本のみ |
| プライバシー | 体重・体調・生理データは**友達に共有しない**。分析は匿名・オプトアウト可。クラッシュはApple標準のみ |
| データ保全 | 端末ローカル(SwiftData)+ 任意でクラウドバックアップ(Apple/Google連携時) |
| 課金 | App内課金(StoreKit 2)。サブスク。復元導線必須 |

## 2. 画面構成(ユーザーが見るもの)

下部タブ(iPhone)/ サイドバー(iPad)の **5タブ** 構成。

| タブ | 役割 | 主な内容 |
|---|---|---|
| **ホーム** | 毎日の起点 | 猫キャラ、連続日数、今週の進捗、記録ボタン、復帰モード、各種お祝い演出 |
| **履歴** | 振り返り | 月カレンダー、月次レビュー、累計実績、連続フリーズ残数、記録一覧 |
| **体重** | 体重管理(**プレミアム限定**) | 推移グラフ、BMI、目標、レポート、生理周期オーバーレイ |
| **友達** | 励まし合い | 友達一覧、週間ランキング、応援(チア)、招待、アカウント連携 |
| **設定** | 各種設定 | プレミアム、テーマ、猫変更、通知、データ書き出し/削除、規約・サポート |

### 2.1 オンボーディング(初回起動)
1. 「一緒にがんばる猫を選ぼう」→ 猫を1匹選択
2. (任意)招待コードを入力
3. 通知の許可を確認 → 「はじめる」

### 2.2 ホーム画面
- **連続日数バッジ**(大きく表示)/ **称号バッジ**(連続中のみ)/ ステータス(達成済み・回復日・あと◯時間)
- **猫シアター**: 大きな猫キャラ(呼吸・浮遊アニメ)+ 吹き出しメッセージ
- **記録ボタン**:「今日の運動を記録する」(未達成時は脈動)
- **復帰モード**: 昨日休んだ人向けに「おかえり」カードを表示
- **紹介スター**: 紹介人数を星で表示(0なら非表示)
- **演出**: 記録完了→ホーム復帰時のみ、節目祝い・称号アップ・紙吹雪を表示(起動時には出さない)
- **復活ポップ**: 連続が途切れたとき、フリーズで救済できる導線

### 2.3 記録フロー
- **記録入力**: 種目(カテゴリ+名前)、時間 or 回数/セット、(任意)体重・生理日・メモ。複数種目可。
- **クイック記録**: ウィジェット/Siri から1タップ記録(種目「クイック記録」・60秒)。
- **記録完了画面**: お祝い背景+猫+連続日数の大表示+「ホームへ戻る」/「もう一種目する」。

### 2.4 履歴タブ
- **月カレンダー**: 達成(緑)/ 回復日(灰)/ 未達成(薄赤)/ フリーズ救済(雪)/ 生理日(★)。日タップで詳細。
- **月次レビュー・週間ハイライト・累計実績**カード(シェア可)
- **連続フリーズ**残数と使用導線、記録一覧(折りたたみ)

### 2.5 体重タブ(プレミアム限定)
- 未加入時はぼかし+ペイウォール(「ホームの記録からの体重入力は無料」と明記)
- 加入時: 最新体重/目標/増減、BMI、推移グラフ(週/月/年/全期間)、生理周期オーバーレイ、履歴

### 2.6 友達タブ
- 未サインイン: 「サインインして友達とつながる」
- サインイン後: 友達一覧(連続日数/今日達成/称号)、並び替え、リスト/公園表示、週間ランキング、QR/招待コードで追加、**応援(チア)**送信、Apple/Google バックアップ

### 2.7 設定タブ
- プレミアム加入/特典、アプリシェア、友達招待、**称号一覧**、後から招待コード入力(登録7日以内)
- テーマカラー、猫キャラ変更、達成時の振動
- 体調・周期の記録ON/OFF、運動詳細の共有ON/OFF(体重・体調は共有されない旨を明示)
- 通知設定、ウィジェット追加ガイド
- **データ書き出し**(JSON)、**すべての記録を削除**、**分析共有のON/OFF**
- ご意見・不具合報告、バージョン、サブスク管理、プライバシー/利用規約/サポート

## 3. コア機能のルール(数値つき)

### 3.1 連続日数(ストリーク)
- **「昨日まで」基準**: 今日まだ記録していなくても連続は0にならず、昨日までの連続を表示。
- **達成日の条件**: その日に**1種目以上**の記録、または**合計60秒以上**の運動。
- フリーズ救済日も達成扱い(連続を橋渡し)。

### 3.2 自動休養(回復日)
- 週**最大2日**まで、運動しなかった日を自動で「回復日」にして連続を切らさない。
- 週は**月曜始まり**。

### 3.3 連続フリーズ(レスキューチケット)
- 月の付与枚数: **無料=月1枚 / プレミアム=月4枚**。
- 紹介確定ごとに**+1枚**(その月)。ただし**月の上限は5枚**(`min(5, base+紹介ボーナス)`)。
- **復活グレース=4日**: 連続が途切れても、直近4日以内の未達成日にフリーズを当てれば連続が復活。

### 3.4 称号(連続日数で進化)— 全11段
| 段 | 連続日数 | 称号 |
|---|---|---|
| 1 | 7日 | みならいネコ |
| 2 | 14日 | かけだしネコ |
| 3 | 30日 | がんばりネコ |
| 4 | 50日 | まいにちネコ |
| 5 | 75日 | きたえネコ |
| 6 | 100日 | つわものネコ |
| 7 | 150日 | ベテランネコ |
| 8 | 200日 | 達人ネコ |
| 9 | 300日 | 仙人ネコ |
| 10 | 365日 | レジェンドネコ |
| 11 | 500日 | ぬしネコ |
- 連続が途切れると称号も下がる(常に現在の連続日数に連動)。背景は段が上がるほど豪華に。

### 3.5 節目のお祝い演出
- 連続: **10/30/50日**(標準)、**100日**(豪華)、**365日**(伝説)など
- 累計: 100日(🎖️)/365日(🏆)/500日(🏆)
- 周年: 1年・2年…(🎉)
- 体重(減量目標時のみ): **−3kg / −5kg / −10kg**

### 3.6 月次レビュー
- 表示: 達成日数 / 月の最長連続 / 合計運動時間(分)/ 種目数 / よく使ったカテゴリ・種目。
- 週間ハイライト・累計(通算日数)も同様のロジック(回復日・フリーズは連続を橋渡し)。

### 3.7 猫の種類(全11種)
- orange(デフォルト)/ black / white / gray / calico / silvertabby / browntabby / siamese / tuxedo / persian / scottish
- **解放条件**: プレミアム加入 **または** 紹介スター**10個**で全種解放。無料・未解放はデフォルトのまま。

### 3.8 体重・BMI
- BMI = 体重(kg) ÷ (身長m)²。区分: やせ<18.5 / 普通18.5–24.9 / 肥満1度25–29.9 / 肥満2度以上≥30。
- 開始体重は初回入力時に自動記録。目標までの予測は直近7日の傾きから外挿。

## 4. 友達・紹介・アカウント

### 4.1 友達機能
- **友達コード**: 6文字(紛らわしいO/0/I/1は除外)。QR/コードで追加→相手が承認。
- **応援(チア)4種**: がんばれ / すごい / 👏 / 🔥
- **週間ランキング**: 今週の達成数(タイブレーク=合計分数)。自分+友達。
- **共有される情報**: 連続日数、今日の達成、週/月の実績、称号、猫の種類、(任意で)運動詳細。
  **体重・体調・生理は共有しない。**
- iOS と Android が**同じバックエンド(Supabase)**でつながる。

### 4.2 友達紹介(リファラル)
- 招待コード=友達コード。
- 報酬: **紹介する側=⭐+1(永久)+ 今月フリーズ+1** / **される側=ウェルカム・フリーズ+1**。
- **確定タイミング**: 紹介された人が**初めて運動を記録**したとき。
- **⭐10個で全猫種を解放**。
- 後から入力は**登録7日以内**かつ紹介者未登録のときのみ。
- サーバ側で改ざん防止(確定の捏造・当事者すり替え・再ミントを拒否)。

### 4.3 アカウント
- **匿名アカウント**(サインイン不要で開始。必要時に自動生成)。
- **Apple / Google 連携**でバックアップ・別端末復元・アカウント切替。
- **アカウント削除**: サーバ関数で全データを連鎖削除(審査要件 5.1.1(v) 対応)。

## 5. 課金・通知・ウィジェット・分析

### 5.1 課金(GOプレミアム)
- 商品: **月額 ¥500** / **年額 ¥3,800**(`com.goexercise.app.premium_monthly` / `..._yearly`)。
- **14日間無料トライアル**(Apple ID×グループにつき1回。消化済みなら「無料」表示は出さない)。
- **特典**: 体重タブ全機能 / 週次・月次レポート / 生理周期オーバーレイ / フリーズ月4枚 / 全猫種 / 減量ご褒美。
- 復元ボタン・サブスク管理リンクを用意(審査要件)。

### 5.2 通知
- **ローカル通知のみ**(リモートプッシュなし)。朝・夜のリマインダー(時刻・頻度を設定可)。
- 7日分の単発通知を都度更新する方式。タップでアプリ内へディープリンク。

### 5.3 ウィジェット / Live Activity
- ホーム画面ウィジェット: 連続日数 / 今日の達成 / クイック記録ボタン。
- 日付が変わると表示を「新しい日・未記録」に自動更新(翌朝の「達成済み」固着を防止)。
- App Group(`group.com.goexercise.app`)でアプリとデータ共有。

### 5.4 分析・プライバシー
- 分析=**TelemetryDeck**。**リリースビルド かつ ユーザーが許可しているときだけ**送信(既定ON・設定でオフ可)。個人特定情報は送らない。
- クラッシュ=Apple標準のみ。

### 6.1 データモデル(主なテーブル / Supabase)
- `profiles`(プロフィール・公開実績)/ `friend_requests`(申請)/ `friendships`(友達関係)/ `cheers`(応援)/ `referrals`(紹介)
