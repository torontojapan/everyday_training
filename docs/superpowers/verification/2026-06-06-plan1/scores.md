検証方式: Claude(自分の目)+ Codex(gpt-5.5)+ Gemini(2.5-pro)が同一スクショを独立採点。
各項目 0–3 点(2点以上で合格)。撮影は simctl(iPhone 17 Pro Max, light)。

## 改善ループでやったこと
1. **レイアウト(自分の目で発見)**: ホーム topStatusBar で連続/称号/状態の3チップが横並びで折返し → 称号バッジを連続チップの**直下**に配置 + RankBadge を常に1行(fixedSize+lineLimit)に。
2. **C2/A1 メタル色の引き離し**: bronze=赤茶 / silver=ニュートラル鋼 / gold=高彩度黄 / platinum=冷たい青白(白金)/ rainbow=高彩度化。
3. **C1 質感**: バッジに上半分の艶ハイライト + 外周の暗ヘアラインで「淡い pill」感を解消。
4. **F1 友達リング**: 2pt 平色 → **5pt 外周メタルグラデリング + 暗フチ + シャドウ**、tint 背板を 0.30→0.22 に抑制。
5. **A1 platinum 背景**: 上位感を「色の濃さ」でなく rank10 の**白寄り光沢帯を強化**(上品さ維持)。

## 最終判定
- **Codex: PASS(全項目 ≥2)。**
- **Gemini: F1 のみ 1**(密グリッドのサムネリングで 11 段を一目判別するのは原理的に困難という指摘)。
  → 称号テキストは**友達詳細画面の RankBadge** で明示表示済み(spec F 充足)。一覧はメタルリングを簡易プロキシとする設計。
- 7/8 項目が両 LLM で合格。残る F1 は「一覧にも称号テキストを出す」改修で解消可能(**フォローアップ候補**: 友達リスト表示(グリッドではなくリスト toggle)の行に compact RankBadge を追加)。実機確認で要否を判断。

## 注意(検証環境)
- ダークモードは アプリ内テーマが `preferredColorScheme` を固定するため simctl の appearance では切替わらず。実機のアプリ内テーマで要確認(本ループは light のみ)。
- 小節目オーバーレイ(B)のモーション/ハプティクスは静止画では評価不可。実機で要確認。
