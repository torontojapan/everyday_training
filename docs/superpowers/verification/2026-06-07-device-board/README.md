# 達成リデザイン A〜F 実機確認ボード(iOS)

Claude が iOS シミュレータで「見える/ロジック」部分を先に検証したスクショ board。
**実機では下の「② デバイス専用チェック」だけ**を確認すれば OK。

## DEBUG 起動シナリオ(各状態を即出し)
Xcode の scheme → Run → Arguments、または `xcrun simctl launch` の引数に:
`--seed-demo-data --seed-scenario <X> --skip-onboarding --no-notification-prompt`
- `rank-7` = 連続7日(rank1 みならいネコ・bronze)
- `monthly` = 30日(rank3 がんばりネコ・silver)
- `rank-100` = 100日(rank6 つわものネコ・gold)
- `yearly` = 365日(rank10 レジェンドネコ・platinum)
- `rank-500` = 500日(rank11 ぬしネコ・rainbow)
- `revive` = 直近で連続が途切れた状態 → **復活ポップ(D)**(※今日が週後半ほど確実。日曜で確認済)
- 友達: `--initial-route friends --mock-seed-friends`
- 称号バッジを純粋に見たい時は `--skip-milestones`(大節目シートを抑止)
※ 初回起動時(永続データ無し)に seed されるので、状態を変えるときは**アプリ削除→再インストール**。

## ② デバイス専用チェック(あなたにお願い ＝ sim では出せない部分)
実機(または TestFlight)で、上の各シナリオを出しながら下だけ確認:

- [ ] **B ハプティクス**: `rank-7` 起動 → 称号アップ!トースト表示時に**軽い振動**。トーストが上から降りて自動で消える**動き**。称号バッジの**shimmer/pop**。
- [ ] **D ハプティクス+復活演出**: `revive` 起動 → 「フリーズを使う(1回)」タップ → **連続が即復活**(連続◯日が戻る)+「連続復活!」演出+**振動**。残枠0(`revive` を2回使う等)で「プレミアムを見てみる」→ **ペイウォール**遷移。「今回はしない」で消えて**再起動しても再表示されない**(節度)。
- [ ] **A モーション**: 高ランク(`rank-500`)の背景 sparkle/光の**ゆらぎ**。設定→アクセシビリティで**視差を減らす(Reduce Motion)** ON 時に粒子/光が**静止**するか。
- [ ] **ダークモード**: 設定タブ → テーマ → **Midnight(ダーク)** に切替 → 各ランクで背景・称号バッジ・友達リングが破綻しないか(コントラスト)。
- [ ] **E 各猫種シェイカー**: 設定→猫を変更(black/calico/siamese 等)→ ホームで**今日未記録**のとき、その猫種のシェイカー版が出るか。記録すると通常の達成猫に戻るか。
- [ ] **F 友達**: 友達タブ → リスト表示(☰)で**称号テキスト(compact)**、グリッド(田)で**メタルリング**。友達詳細で**称号バッジ**。
- [ ] **課金導線**: 復活ポップの「プレミアムを見てみる」/ 設定のプレミアム → ペイウォールに**「全11種の猫から選べる」**特典が載っているか。
