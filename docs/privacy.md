# プライバシーポリシー — GO エクササイズ

**最終更新日: 2026-06-01**

GO エクササイズ（以下「本アプリ」）は、ユーザーのプライバシーを最大限尊重します。本ポリシーは、本アプリにおける個人情報の取り扱いについて定めるものです。

> **現行バージョンについて**: 友達機能（第2章）は有効です。ユーザーが「友達とつながる」操作（友達追加（友達コードの入力・QRコードやリンクの読み取りを含む）や自分の友達コードの表示など）を行った場合に限り、表示名・連続記録などの共有プロフィールが外部データベース（Supabase）に保存されます（**友達タブを開いただけでは保存されません**）。**利用状況の分析（第4章）は現在無効**で、解析データの送信は行っていません。体重・体調の記録、および運動記録のメモは外部送信されず、友達にも共有されません。友達機能で共有されるのは、表示名・連続記録・今日のカテゴリ／種目名などの明示項目に限られます（種目ごとの回数・セット数・運動時間は、設定でオンにした場合のみ共有）。

## 1. 端末内に保存する情報

本アプリは、以下の情報を **原則として端末内のみ** に保存します。友達機能で共有する項目（第2章）を除き、サーバーや第三者へ送信しません。

- 運動記録（カテゴリ、種目名、時間、回数、セット数、メモ、実施日時）
- 連続記録 / 週間達成率の集計データ
- 体重・体調（生理日）記録（ユーザーが任意で入力する場合のみ）
- 通知設定（ON/OFF、通知時刻）
- アプリ内設定（テーマ、効果音・振動 ON/OFF 等）

これらは Apple 標準の SwiftData により、ユーザーの端末（iPhone / iPad）に保存されます。

## 2. 友達機能で外部データベースに保存する情報（オプトイン）

ユーザーが「友達とつながる」操作（友達追加（友達コードの入力・QRコードやリンクの読み取りを含む）や自分の友達コードの表示など）を行った場合に限り、以下の情報をプラットフォーム中立な外部データベース（Supabase。匿名認証を使用しログイン不要）に保存します（**友達タブを開いただけでは保存されません**）。Apple・Android いずれの端末からも同じ友達としてつながれる設計です。

| 項目 | 用途 | 共有範囲 |
|---|---|---|
| 友達コード (6 桁の英数字) | 相手の検索・申請受付 | 公開（コードを知る相手のみが検索可能） |
| 表示名 (例: 「ジュン」) | 友達一覧での表示 | 友達のみ |
| ユーザー名 (例: 「jun88」) | 検索用 | 公開 |
| 現在の連続記録日数 | 友達一覧の表示 | 友達のみ |
| 累計達成日数 | 友達一覧の表示 | 友達のみ |
| 今日の達成有無 / カテゴリ名 / 種目名 | 友達カードでの状態確認 | 友達のみ |
| 週間の達成状況（曜日ごとの達成有無）/ 週・月の運動時間・達成日数 | 友達一覧・週間ランキングの表示 | 友達のみ |
| 猫キャラの種類 | 友達一覧でのアバター表示 | 友達のみ |
| 装飾ランク (バンダナ / メダル等) | 友達一覧での表示 | 友達のみ |
| 応援スタンプ (cheer) の送信履歴 | 友達への通知 | 送信先のみ |
| 匿名アカウントの識別子（Supabase Anonymous Auth が発行。氏名・メール等とは結びつきません） | アカウント同定 | 友達機能のため |

以下の情報は外部に送信されず、友達にも共有されません:

- 体重・体調（生理日）記録
- 通知設定 / アプリ内設定

※ 種目ごとの詳細（回数・セット数・運動時間）は通常共有されませんが、設定で「種目の詳細も共有」をオンにした場合に限り、今日の種目の詳細が友達に共有されます。メモは共有されません。

ユーザーは友達機能の「サインアウト」によりいつでも上記データを外部データベース（Supabase）から削除できます。

## 3. 収集しない情報

- 氏名、メールアドレス、電話番号などの個人を特定する情報（友達機能では氏名・メール等と結びつかない匿名アカウント識別子のみを使用します）
- 位置情報
- 広告識別子 (IDFA) および広告目的のトラッキング
- 連絡先・写真・カレンダー等の端末データ
- 運動・体重・体調の **記録内容そのもの**（後述の利用状況分析にも送信されません。※友達機能では、今日のカテゴリ名・種目名や連続記録・達成状況などの一部の運動関連情報を、第2章のとおり友達に共有します）
- 第三者によるクラッシュ解析 SDK（クラッシュ情報は Apple 標準の仕組みで、ユーザーが共有を許可した場合に限り匿名で開発者へ提供されます）

## 4. 利用状況の分析（TelemetryDeck）

**※ 現行バージョンではこの計測は無効で、解析データは送信していません。** 将来有効化する場合の取り扱いを以下に記載します。

本アプリは、機能改善のために匿名の利用状況を計測する場合があります。計測には、プライバシー保護を重視した解析サービス **TelemetryDeck**（EU 拠点・GDPR 準拠）を使用します。

- 送信されるのは「アプリ起動」「記録の作成」「課金画面の表示」などの **匿名のイベント名と最小限の付随情報（例: 運動カテゴリ名）** のみです。
- 氏名・メール・友達コード・記録内容そのものなど、**個人を特定できる情報は送信しません**。
- 広告識別子 (IDFA) は使用せず、広告目的のトラッキングや第三者へのデータ販売も行いません。TelemetryDeck は端末由来の識別子をハッシュ化した匿名 ID のみを扱い、そこから個人を逆引きすることはできません。

これら以外の第三者（広告ネットワーク・SNS 等）とは一切連携していません。

友達機能で使用する Supabase は、プライバシー保護を重視したオープンソースのバックエンドサービスで、行レベルセキュリティにより各ユーザーのデータは本人と友達のみがアクセスできるよう保護されます。

## 5. データの保持期間

- **端末内データ**: ユーザーが端末内で保持している限り、本アプリのデータは端末内に存在します。本アプリのアンインストールにより、すべてのデータは端末から削除されます。
- **外部データベース（Supabase）上のデータ**: 友達機能のサインアウト時に共有プロフィール・友達関係・応援履歴を削除します。
- **未使用の匿名アカウントの自動削除**: 友達が1人もおらず、申請もなく、一定期間（30日）更新がない匿名アカウントは、共有プロフィールごと自動的に削除されます。

## 6. 子どもの利用

本アプリは年齢区分「4+」として提供されますが、保護者の方は、お子様の利用について適切に判断し、必要に応じて見守りをお願いします。友達機能は表示名・ユーザー名等を他のユーザーに公開する仕組みですので、未成年が利用する場合は保護者の同意のもとで使用してください。

## 7. 通知

本アプリは、ユーザーが許可した場合に限り、ローカル通知（端末内で完結する通知）を送信します。

友達申請・応援スタンプは、現在のバージョンでは友達画面を開いた際の更新で反映されます（プッシュ通知は今後のアップデートで対応予定）。

## 8. 将来のアップデート

将来のアップデートで以下の機能を追加する場合、別途許可をいただいたうえで連携を行います。

- Apple Watch 連携
- Apple ヘルスケア連携

これらが有効化された際は本ポリシーを更新し、アプリ内および本ドキュメントで告知します。

## 9. ポリシーの変更

本ポリシーが変更された場合、本ドキュメントを更新し、最終更新日を改めます。重要な変更がある場合はアプリ内で通知します。
