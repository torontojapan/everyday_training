# GOエクササイズ 本番リリース QA チェックリスト

最終更新: 2026-05-29

本番(App Store 配信)で全機能が正しく動くことを確認するための手動 QA 項目。
自動テスト(Unit 175 XCTest + Swift Testing / UI 17 = 計 257 件)でカバー済みの
領域も、本番固有(実機 / StoreKit / 権限 / CloudKit)の挙動は手動確認が必須。

## 凡例

- 🧪 シミュレータで確認可
- 📱 実機必須(Live Activity / ウィジェット / 通知配信 / Push など)
- 🍎 Apple Developer 加入後(署名 / IAP / CloudKit)
- 🤖 自動テストで一部カバー済(回帰は CI 相当で担保)

## 特に落とし穴になりやすい 3 点

1. **友達機能は現状 `MockFriendsService` = 本番では実際に動かない**(ローカルのみ)。
   CloudKit 実装まで「友達」を出すなら要実装、出さないなら v1 で隠す判断が必要。
2. **課金は Sandbox 実機テストが必須**。`simctl` 直接起動では StoreKit Configuration が
   注入されず「商品情報読込中…」になる。Xcode 実行 or 実機 Sandbox で確認する。
3. **Live Activity / ウィジェット / 通知配信は実機でしか検証できない**。
