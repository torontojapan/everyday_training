# GOエクササイズ UI/UX 改善提案 — Codex 視点

既存の `uxrevamp_claude.md` / `uxrevamp_gemini.md` は、TabView 化、猫中心ホーム、1タップ記録、Positive-Only Calendar、友達公園、Interactive Widget / Live Activity など、体験の大枠をかなり強く提示している。  
この提案ではそこを繰り返さず、Phase 7.0 までの実装を前提に、毎日の継続率を落としにくくする「復帰・配慮・微細な報酬」の設計に絞る。

## 1. 今日の最小ラインを選べる「ミニマム宣言」
- **観察**: 毎日エクササイズアプリは、元気な日と疲れた日の差が大きい。達成条件が常に同じだと、忙しい日に記録自体を避けやすい。
- **提案**: ホーム上部に「今日はどのくらいでOKにする？」を軽く選べるチップを置く。通常・軽め・回復の3段階にし、軽めの日も達成として扱うが、履歴には小さな葉アイコンなどで区別する。運動量を競わせるより、アプリを閉じないことを優先する。
- **見た目**:
```text
┌────────────────────┐
│ 今日のライン          │
│ [いつも通り] [軽め] [回復] │
│                    │
│        (=^･ω･^=)    │
│    軽めでも続けば勝ち │
└────────────────────┘
```
- **工数**: M (半日)

## 2. 連続が切れた翌日の「復帰ファースト」ホーム
- **観察**: 未達成の翌日は、アプリを開く心理的ハードルが一番高い。カレンダーで失敗を見せないだけでは、復帰の最初の一歩がまだ弱い。
- **提案**: 連続が切れた翌日のみ、ホームの主文言とCTAを復帰専用に差し替える。「再開」ではなく「今日だけ戻る」に近い低圧コピーにし、記録完了後は通常ホームへ戻す。ストリーク数の減少より、復帰成功の演出を優先する。
- **見た目**:
```text
┌────────────────────┐
│        猫が玄関で待つ │
│                    │
│   昨日はおやすみ。    │
│   今日は30秒だけ戻る？ │
│                    │
│     [ ただいま記録 ]  │
└────────────────────┘
```
- **工数**: S (<2h)

## 3. Dynamic Type / VoiceOver 前提の「記録セーフモード」
- **観察**: 猫画像や演出が中心になるほど、文字拡大・VoiceOver・Reduce Motion 利用時に操作の主導権を失いやすい。
- **提案**: アクセシビリティ設定を検知し、記録導線だけは常にテキスト優先の縦リストに切り替えられるセーフモードを用意する。猫の状態は `accessibilityLabel` で「今日の猫: 元気、記録済み」のように明示し、演出画像は操作対象から外す。Reduce Motion 時はパーティクルではなく色と短いハプティックで達成を伝える。
- **見た目**:
```text
┌────────────────────┐
│ 今日の状態: 未記録     │
│ 猫: 待っている         │
│                    │
│ [運動を記録する]       │
│ [履歴を見る]           │
│ [友達の状況を見る]     │
└────────────────────┘
```
- **工数**: M (半日)

## 4. 記録直後の「次の一歩」だけを出すマイクロリワード
- **観察**: 祝祭演出は達成感を作れるが、毎日同じ演出だけだと慣れる。記録直後に次回起動の理由を1つ残せると、翌日の保持率に効く。
- **提案**: 記録完了後、3秒だけ「明日の小さな予約」を出す。例: 明日は同じ時間に猫が待つ、友達にエールを返す、月次レビューに一言メモを残す。入力項目を増やすのではなく、ユーザーが選んだ1つだけを明日の通知・ホーム文言に反映する。
- **見た目**:
```text
┌────────────────────┐
│ 記録できました        │
│ しっぽぱたぱた +1     │
│                    │
│ 明日はどう待つ？       │
│ [同じ時間] [朝に一言]  │
└────────────────────┘
```
- **工数**: M (半日)

## 5. 友達機能に「見せる範囲」をその場で選べる共有レベル
- **観察**: ランキングや友達公園は楽しい一方で、運動習慣が途切れた時に他人から見えることが負担になる可能性がある。
- **提案**: 友達タブに一括プライバシーではなく、今週だけの共有レベルを置く。「通常表示」「猫だけ表示」「休憩中表示」の3段階にする。記録日数や順位を隠しても、公園には存在できる設計にして、ソーシャルから離脱しにくくする。
- **見た目**:
```text
┌────────────────────┐
│ 友達への見え方        │
│ [通常] [猫だけ] [休憩中] │
│                    │
│ 公園には参加中         │
│ 数字は今週だけ非表示   │
└────────────────────┘
```
- **工数**: M (半日)

## 6. 通知を「催促」ではなく猫の予定として設計する
- **観察**: 習慣化アプリの通知は、毎日同じ文面だとすぐ無視される。Live Activity / Widget があっても、通知疲れが起きると接触面全体が弱くなる。
- **提案**: 通知設定を時刻だけでなく「猫の待ち方」で選ばせる。静かに待つ・短く呼ぶ・友達の動きがあった時だけ、のようなモードにし、文面も連続日数ではなく状況に合わせる。未達成が続いたら通知頻度を自動で下げ、復帰しやすい1通だけにする。
- **見た目**:
```text
┌────────────────────┐
│ 通知の性格            │
│ ○ 静かに待つ          │
│ ● ひとこと呼ぶ        │
│ ○ 友達が動いた時だけ  │
│                    │
│ 例: 猫が玄関で待ってます │
└────────────────────┘
```
- **工数**: S (<2h)

## 7. 月次レビューに「次月の作戦」カードを追加する
- **観察**: 月次レビューは振り返りとして強いが、見て終わりだと翌月の行動変化に接続しにくい。
- **提案**: 月次レビューの最後に、実績から自動生成した「来月はこれだけ」カードを1枚追加する。例: 失敗しやすい曜日、達成しやすい時間帯、軽め宣言のおすすめ日を出す。共有用のブランドカードとは別に、本人だけが見る作戦カードとして扱う。
- **見た目**:
```text
┌────────────────────┐
│ 来月の作戦            │
│ ・火曜は軽めでOK       │
│ ・21時台が続きやすい   │
│ ・3日連続より週4を狙う │
│                    │
│ [この作戦で始める]     │
└────────────────────┘
```
- **工数**: L (1日以上)
