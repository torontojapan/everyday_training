# プライバシーポリシー — GO エクササイズ

**最終更新日: 2026-06-11**

GO エクササイズ（以下「本アプリ」）は、ユーザーのプライバシーを最大限尊重します。本ポリシーは、本アプリにおける個人情報の取り扱いについて定めるものです。

> **現行バージョンについて**: 友達機能（第2章）は有効です。ユーザーが友達機能を利用した場合に限り、表示名・連続記録などの共有プロフィールが外部データベース（Supabase）に保存されます。**利用状況の分析（第4章）は匿名**で行い（個人を特定しません）、設定からいつでも停止（オプトアウト）できます。体重・体調の記録、および運動記録のメモは、友達には一切共有されません。外部送信も原則ありませんが、ユーザーが設定で「**記録をクラウドにバックアップ**」（第3章・オプトイン、既定オフ）をオンにした場合に限り、機種変更・再インストール時の復元のために**本人だけが読み書きできる領域**へ保存されます。友達機能で共有されるのは、表示名・連続記録・今日のカテゴリ／種目名などの明示項目に限られます（種目ごとの回数・セット数・運動時間は、設定でオンにした場合のみ共有）。機種変更などに備えてデータを引き継ぎたい場合は、任意で Apple または Google アカウントとの連携（バックアップ）を行えます（第2章）。連携や友達機能をやめたい場合は、いつでもアプリ内から**アカウントを完全に削除**できます（第6章）。

## 1. 端末内に保存する情報

本アプリは、以下の情報を **原則として端末内のみ** に保存します。友達機能で共有する項目（第2章）と、ユーザーが任意でオンにした場合のクラウドバックアップ（第3章）を除き、サーバーや第三者へ送信しません。

- 運動記録（カテゴリ、種目名、時間、回数、セット数、重さ、メモ、実施日時）
- 連続記録 / 週間達成率の集計データ
- 体重・体調（生理日）記録（ユーザーが任意で入力する場合のみ）
- 通知設定（ON/OFF、通知時刻）
- アプリ内設定（テーマ、効果音・振動 ON/OFF 等）

これらは Apple 標準の SwiftData（Android 版では Room データベース）により、ユーザーの端末に保存されます。

## 2. 友達機能で外部データベースに保存する情報（オプトイン）

ユーザーが友達タブを開くと、友達コードの発行・表示のために匿名アカウントと以下の共有プロフィールがプラットフォーム中立な外部データベース（Supabase。匿名認証を使用しログイン不要）に作成されます。連続記録などの実績情報が共有されるのは**友達としてつながった相手のみ**で、つながるまでは誰からも閲覧されません（友達コード・ユーザー名のみ、コードを知る相手が検索に使用できます）。Apple・Android いずれの端末からも同じ友達としてつながれる設計です。一定期間使われなかった匿名アカウントは自動削除されます（第6章）。

| 項目 | 用途 | 共有範囲 |
|---|---|---|
| 友達コード (6 桁の英数字) | 相手の検索・申請受付 | 公開（コードを知る相手のみが検索可能） |
| 表示名 (例: 「ジュン」) | 友達一覧での表示 | 友達のみ |
| ユーザー名 (例: 「jun88」) | 検索用 | 公開 |
| 現在の連続記録日数 | 友達一覧の表示 | 友達のみ |
| 累計達成日数 | 友達一覧の表示 | 友達のみ |
| 今日の達成有無 / カテゴリ名 / 種目名 | 友達カードでの状態確認 | 友達のみ |
| 週間の達成状況（曜日ごとの達成有無）/ 週・月の運動時間・達成日数 | 友達一覧・週間ランキングの表示 | 友達のみ |
| 猫キャラの種類 | 友達一覧でのアバター表示 | 友達のみ |
| 装飾ランク (バンダナ / メダル等) | 友達一覧での表示 | 友達のみ |
| 応援スタンプ (cheer) の送信履歴 | 友達への通知 | 送信先のみ |
| 匿名アカウントの識別子（Supabase Anonymous Auth が発行。氏名・メール等とは結びつきません） | アカウント同定 | 友達機能のため |

以下の情報は友達機能では送信されず、友達にも共有されません（体重・体調はユーザーが第3章のクラウドバックアップをオンにした場合に限り、本人専用の領域へ保存されます）:

- 体重・体調（生理日）記録
- 通知設定 / アプリ内設定

※ 種目ごとの詳細（回数・セット数・運動時間）は通常共有されませんが、設定で「種目の詳細も共有」をオンにした場合に限り、今日の種目の詳細が友達に共有されます。メモは共有されません。

### Apple / Google アカウントとの連携（任意・バックアップ／復元）

友達データは初期状態では端末に紐づく匿名アカウントに保存されます。機種変更や再インストールに備えてデータを引き継ぎたい場合に限り、ユーザーは任意で **Apple（Sign in with Apple）** または **Google** アカウントとの連携を行えます。連携を行うと、認証基盤（Supabase Auth）が当該プロバイダのアカウント識別子を保持し、同じアカウントでの復元時に既存の友達データへ再接続できるようにします。

- この識別子は **バックアップ／復元のためだけ** に使用し、広告・マーケティングには一切利用せず、友達にも共有しません。公開プロフィール（友達コード・表示名等）とは別に管理されます。
- Apple との連携では、Apple の「メールを非公開」機能により、ご自身のメールアドレスを開発者に知らせずに連携できます。当アプリはメールアドレスを友達に共有したり、本人確認以外の目的で利用したりしません。
- 連携は任意です。連携せず匿名アカウントのまま友達機能を使い続けることもできます。

ユーザーは友達機能の「サインアウト」によりいつでも上記の共有データを外部データベース（Supabase）から削除できます。また、アプリ内の「アカウントを削除」から、連携の有無にかかわらず**アカウントと関連データを完全に削除**できます（第6章）。

## 3. 記録のクラウドバックアップ（オプトイン・既定オフ）

設定の「**記録をクラウドにバックアップ**」をオンにした場合に限り、機種変更（iPhone ↔ Android を含む）や再インストール時に記録を復元できるよう、以下の記録をあなたのアカウント（第2章の匿名アカウント。任意で Apple／Google 連携可）に紐づく専用領域（Supabase）へ保存します。**この設定は既定でオフ**であり、オフのままなら本章のデータが外部へ送信されることはありません。

- 運動記録（カテゴリ、種目名、時間、回数、セット数、重さ、メモ、実施日時）
- 体重記録（体重、メモ、記録日時）
- 体調（生理日）記録
- 連続記録の保護（フリーズ）を使用した日

このバックアップ領域は、データベースの行レベルセキュリティにより**本人だけが読み書きできます**。**友達を含む他のユーザーには一切公開されません**。バックアップの内容を広告・マーケティング・分析（第5章）に利用することもありません。

- **オフにする**: 設定からいつでもオフにできます。オフにすると以後の同期は停止します（保存済みのバックアップは復元用に残ります）。
- **削除する**: 設定の「すべての記録を削除」を行うと、端末内の記録と併せてクラウド上のバックアップも完全に削除されます。アプリ内の「アカウントを削除」（第6章）でも、バックアップを含む全データが削除されます。
- **復元**: 新しい端末で同じアカウント（Apple／Google 連携、または同一の匿名セッション）にサインインすると、バックアップが自動的に取り込まれ、本機能がオンになります。

## 4. 収集しない情報

- 氏名、メールアドレス、電話番号などの個人を特定する情報（友達機能では原則として氏名・メール等と結びつかない匿名アカウント識別子のみを使用します。ユーザーが任意で Apple／Google 連携を行った場合のみ、認証基盤がプロバイダのアカウント識別子をバックアップ／復元のために保持します。第2章参照）
- 位置情報
- 広告識別子 (IDFA) および広告目的のトラッキング
- 連絡先・写真・カレンダー等の端末データ
- 運動・体重・体調の **記録内容そのもの**（後述の利用状況分析にも送信されません。※友達機能では、今日のカテゴリ名・種目名や連続記録・達成状況などの一部の運動関連情報を、第2章のとおり友達に共有します。※ユーザーが第3章のクラウドバックアップをオンにした場合に限り、復元のために本人専用の領域へ保存されます）
- 第三者によるクラッシュ解析 SDK（クラッシュ情報は Apple 標準の仕組みで、ユーザーが共有を許可した場合に限り匿名で開発者へ提供されます）

## 5. 利用状況の分析（TelemetryDeck）

本アプリは、機能改善のために匿名の利用状況を計測します。計測には、プライバシー保護を重視した解析サービス **TelemetryDeck**（EU 拠点・GDPR 準拠）を使用します。

- 送信されるのは「アプリ起動」「記録の作成」「課金画面の表示」などの **匿名のイベント名と最小限の付随情報（例: 運動カテゴリ名）** のみです。
- 氏名・メール・友達コード・記録内容そのものなど、**個人を特定できる情報は送信しません**。
- 広告識別子 (IDFA) は使用せず、広告目的のトラッキングや第三者へのデータ販売も行いません。TelemetryDeck は端末由来の識別子をハッシュ化した匿名 ID のみを扱い、そこから個人を逆引きすることはできません。
- **オプトアウト**: 設定 →「プライバシー」→「利用状況の分析を共有」を OFF にすると、以降は一切送信しません（既定は ON ですが、いつでも停止できます）。

これら以外の第三者（広告ネットワーク・SNS 等）とは一切連携していません。

友達機能・クラウドバックアップで使用する Supabase は、プライバシー保護を重視したオープンソースのバックエンドサービスで、行レベルセキュリティにより各ユーザーのデータは本人（友達機能の共有項目は本人と友達）のみがアクセスできるよう保護されます。

## 6. データの保持期間

- **端末内データ**: ユーザーが端末内で保持している限り、本アプリのデータは端末内に存在します。本アプリのアンインストールにより、すべてのデータは端末から削除されます。
- **外部データベース（Supabase）上のデータ**: 友達機能のサインアウト時に共有プロフィール・友達関係・応援履歴を削除します。
- **クラウドバックアップ（第3章）**: 設定の「すべての記録を削除」で端末内の記録と併せて完全に削除されます。バックアップ設定をオフにしただけの場合は、復元に備えて保存済み分が残ります（完全に消したい場合は「すべての記録を削除」または「アカウントを削除」をご利用ください）。
- **アカウントの完全削除**: アプリ内の「アカウントを削除」から、共有プロフィール・友達関係・応援履歴・クラウドバックアップに加え、認証アカウント本体（Apple／Google 連携を行っている場合はその連携情報を含む）と全端末のログインセッションを完全に削除できます。削除後は同じアカウントで復元しても以前のデータは戻りません。
- **未使用の匿名アカウントの自動削除**: 友達が1人もおらず、申請もなく、クラウドバックアップ（第3章）も保存されておらず、一定期間（30日）更新がない匿名アカウントは、共有プロフィールごと自動的に削除されます（バックアップを保存しているアカウントは削除されません）。

## 7. 子どもの利用

本アプリは年齢区分「4+」として提供されますが、保護者の方は、お子様の利用について適切に判断し、必要に応じて見守りをお願いします。友達機能は表示名・ユーザー名等を他のユーザーに公開する仕組みですので、未成年が利用する場合は保護者の同意のもとで使用してください。

## 8. 通知

本アプリは、ユーザーが許可した場合に限り、ローカル通知（端末内で完結する通知）を送信します。

友達申請・応援スタンプは、現在のバージョンでは友達画面を開いた際の更新で反映されます（プッシュ通知は今後のアップデートで対応予定）。

## 9. 将来のアップデート

将来のアップデートで以下の機能を追加する場合、別途許可をいただいたうえで連携を行います。

## 10. ポリシーの変更

本ポリシーが変更された場合、本ドキュメントを更新し、最終更新日を改めます。重要な変更がある場合はアプリ内で通知します。
