# 🐱 シリアルエクササイズ

猫キャラクターと一緒に、毎日1分から運動を習慣化する iOS アプリ。

> 🐱「今日も1分だけやってみよ？」

## 特長

- 🔥 **1分でOK** — 1種目以上、または1分以上の運動で「今日も達成」
- 📅 **連続記録 + 週間達成率** — 続けるのが楽しくなる可視化
- 😴 **自動で休養日** — 週2回までの未記録日は「回復日」扱い、連続記録は維持
- 🐱 **7状態の猫キャラ** — 朝はにこにこ、夜はそわそわ、達成したら大喜び
- 📲 **ウィジェット** — ホーム画面に残り時間 / 達成率 / 猫メッセージ
- 🔔 **やさしい通知** — 1日2回、時刻はいつでも変更可

## プライバシー方針

記録は **端末内のみに保存**。アカウント登録不要、外部サーバーへの送信なし、サードパーティ SDK なし。
