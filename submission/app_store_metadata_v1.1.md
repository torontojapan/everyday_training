## アプリ説明文 (4000字以内・絵文字なし)

```
「今日も1分だけやってみよ。」

GO エクササイズは、かわいい猫キャラクターと一緒に、毎日の運動をたった1分から続けられる習慣化アプリです。

【こんな人におすすめ】
・運動を始めたいけど、なかなか続かない
・筋トレ、ヨガ、ストレッチを軽く記録したい
・友達と励まし合いながら続けたい
・猫と一緒だと頑張れる気がする

【1分でOK、毎日続けられる】
1種目以上、または1分以上の運動で「今日も達成」。
ハードルを下げて、無理なく続けられます。

【連続記録と週間達成率】
毎日の達成が連続記録に。「12日連続」「今週 4/7 達成」が一目でわかります。

【自動で休養日】
週2回までの未記録日は「回復日」として連続記録に組み込み。
無理に毎日詰め込まなくて大丈夫です。

【友達とつながって応援し合う】
友達コードやQRコード、ユーザー名検索で簡単につながれます。
お互いの連続記録・今日のカテゴリ・週間達成を一覧で確認でき、
「がんばれ」「すごい」「拍手」「応援」の4種スタンプで励まし合えます。
共有されるのはカテゴリと種目名まで。体重・体調などのプライベートな記録は端末内にとどまります。
（種目ごとの回数・セット数・運動時間は、設定でオンにした場合のみ共有）

【12ポーズの猫キャラクター】
朝はにこにこ、昼は心配、夜はおねだり、達成したら大喜び、回復日にはヨガでのんびり。
連続記録が伸びるたびに、装飾もバンダナ、ヘッドバンド、メダル、王冠と段階的にレベルアップ。

【達成感を高める祝祭演出】
特別な節目には、振動とアニメーションで盛大にお祝い。100日連続や1周年など、達成感がしっかり残ります。

【ウィジェットで毎日リマインド】
ホーム画面に「あと何時間」「今週の達成率」「猫メッセージ」。タップですぐ記録画面へ。

【やさしい通知】
1日2回、猫が「やろ？」とお願い。頻度や時間は自由に変更できます。

【シンプルな記録】
カテゴリ(筋トレ/有酸素/ヨガ/ストレッチ/筋膜リリース/その他)を選び、
種目・時間・回数・セット数・メモを記録するだけ。複数種目もまとめて記録できます。

【体重・体調記録(任意)】
体重はホームから無料で記録。推移グラフ・BMI・週次/月次レポート・周期オーバーレイは GOプレミアムで解放。

【GOプレミアム】
体重タブの全機能と、連続記録フリーズ月4回(無料は月1回)を解放。
月額 500円 / 年額 3,800円、14日間無料。いつでも解約できます。

【プライバシー】
運動・体重・体調などの記録は端末内に保存します。「友達とつながる」操作をしたときに限り、
表示名・連続記録・今日のカテゴリ/種目名などの共有プロフィールが保存されます
（友達タブを開いただけでは保存されません）。体重・体調・メモは共有されません。解析・トラッキングは行いません。

「無理しなくていいから、ちょっとだけやろ。」
```

## App Privacy — **収集あり (友達機能。トラッキングなし)**

> v1.0 は「収集なし」だったが、友達機能解禁で **「データを収集する」** に変更。
> いずれも **App機能のため**で、**トラッキングには使用しない**。`PrivacyInfo.xcprivacy` と整合。

### Data Linked to You (ユーザーに紐づく / トラッキングなし)

| カテゴリ | データタイプ | 用途 |
|---|---|---|
| Health & Fitness | Fitness (連続記録・累計達成日・今日の達成有無・週/月の運動時間・達成日数) | App Functionality (友達一覧・ランキング) |
| User Content | Other User Content (表示名・ユーザー名・友達コード・今日のカテゴリ/種目名・装飾・猫キャラの種類・応援スタンプ。詳細=回数/セット/分はopt-in時のみ) | App Functionality (友達機能) |
| Identifiers | User ID (Supabase 匿名認証の識別子) | App Functionality (アカウント同定) |

### Data Not Collected
- Contact Info / Location / Financial / Browsing / Purchases / 体重・体調・メモ / 解析(TelemetryDeck未有効)

### Tracking
`Used to Track You: No`
